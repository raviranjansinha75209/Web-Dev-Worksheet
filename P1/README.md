# P1 – Project folder and terminal navigation

## Aim
Create a project folder and practise moving between folders using terminal commands.

## Commands
```bash
pwd
ls
mkdir web-development-lab
cd web-development-lab
mkdir P1 P2 P3 P4
cd P1
pwd
cd ..
```

## Result
The project folder and practical folders are created, and terminal navigation commands are practised.
