# P2 – Portfolio repo with an initial commit

## Aim
Create a Git repository for the portfolio practical and save the first version using an initial commit.

## Commands
```bash
git init
git status
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/web-development-lab.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. Add the remote only once for a repository.

## Result
A local Git repository is created and its initial commit can be pushed to GitHub.
