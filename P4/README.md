# P4 – GitHub README and version tags

## Aim
Add project documentation and create a version tag to mark a stable version.

## Commands
```bash
git add README.md
git commit -m "Add project README"
git tag -a v1.0 -m "First lab version"
git push origin main
git push origin v1.0
git tag
```

## Result
The repository has a README file and a version tag named `v1.0`.
