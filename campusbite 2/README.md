# CampusBite — Basic HTML & CSS

A simple beginner-friendly food menu webpage made with **HTML and CSS only**.

## Files
- `index.html` — page content and structure.
- `styles.css` — basic mobile-first styling.

## Run the project
1. Extract `CampusBite_Basic.zip`.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.

## Included
- Header and navigation: Menu, Specials, Contact
- Today's Special text banner
- Six menu items with names and prices
- Footer with contact information
- Viewport meta tag
- 90% content container
- One-column grid with a 1rem gap
- Full-width navigation links with comfortable padding
- No photos, no JavaScript, and no media queries

## Check mobile width
Open the page in Chrome, open DevTools, enable Device Toolbar, and test widths of 320px and 390px. Confirm there is no horizontal scrolling.

This project is intentionally basic and uses text-only menu cards.
